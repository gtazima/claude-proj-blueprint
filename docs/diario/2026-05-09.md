### Backend FastAPI

Configuração via `pydantic_settings`:

```python
database_url: str = "sqlite:///./agroecologia.db"          # SQLite local dev
completion_undo_window_seconds: int = 300                   # janela de undo = 5min
allowed_origins: str = "http://localhost:5173,..."          # CORS
```

- **CORS:** `allow_origins=["*"]` em produção — deliberado, pois Cloudflare Access protege na borda
- **Dockerfile** + `render.yaml` com `region: ohio` (melhor free tier para latência Brasil)
- Dependência `psycopg2-binary` adicionada para conexão com Supabase PostgreSQL

### PWA configurado

`vite-plugin-pwa` com estratégia **NetworkFirst** para chamadas à API:

```ts
urlPattern: ({ url }) =>
  url.pathname.startsWith("/api") || url.hostname.endsWith("onrender.com")
handler: "NetworkFirst"
networkTimeoutSeconds: 5   // se timeout → usa cache
maxAgeSeconds: 86400       // cache válido por 24h
```

- Manifest: `start_url=/tarefas`, tema `#15803d`, display `standalone`
- Funciona instalável como app em desktop e mobile

## Decisões tomadas

| Decisão | Justificativa |
|---|---|
| Render free tier para backend | Zero custo no MVP; aceita cold start de ~30s |
| `allow_origins=["*"]` no FastAPI | Cloudflare Access é o guardião real — CORS aberto por dentro, fechado por fora |
| NetworkFirst com timeout 5s no Service Worker | Backend no Render pode hibernar; fallback para cache evita tela em branco |
| `region: ohio` no Render | Única região free tier com latência razoável para Brasil (~150ms) |
