# Diário de Sessão — 2026-05-29

## O que foi feito

### 1. Redesign do encadeamento de tarefas (concluído)

**Problema:** A feature de encadeamento modificava o `task.title` no banco com sufixo `| pos/total`,
quebrando a sincronização com Google Tasks.

**Mudanças backend:**
- `chain.py`: removida toda lógica de mutação de título; adicionado `get_chain_tasks()`
- `routes/tasks.py`: novo endpoint `GET /tasks/chain/{chain_id}/tasks`
- `migrations/007_restore_base_titles.sql`: restaura títulos corrompidos (`base_title → title`)

**Mudanças frontend:**
- `ChainModal.tsx`: novo componente — lista da cadeia, destaque tarefa atual, unlink, fecha com Esc
- `TaskCard.tsx`: badge `pos/total` virou botão clicável que abre ChainModal
- `tasks.ts`: adicionado `getChainTasks(chainId)`

**Deploy:** Migration 007 aplicada. Commit `ac52291` + Cloudflare `8720911c`.

### 2. Fix picker de encadeamento (concluído)

**Problema:** Picker só mostrava chain tails + tarefas sem cadeia. Tarefas no meio de uma cadeia
(posição 1, 2…) eram invisíveis — usuário não conseguia selecionar a 3ª tarefa de uma cadeia.

**Fix:** `CreateTaskModal.tsx` — todas as tarefas encadeadas aparecem primeiro (priorizadas, com badge
`pos/total`), depois as sem cadeia. Commit `573b165`. Cloudflare `792d8637` deployado.
