# Diário de sessão — 2026-05-13

## O que foi feito

### 1. Sync Google Tasks — instantâneo + lista única

Problema: sync tinha latência de até 60s; lógica confusa com duas listas.

Solução:
- `push_task_now(task_id)` em `google_sync.py` — fire-and-forget via BackgroundTasks
- Todo endpoint de write dispara sync imediato após responder ao cliente
- Worker de 60s mantido como fallback de reconciliação
- Lista "memória" removida — todas as tarefas vão para "AgroecologIA"

### 2. Restrição de janela de 5 minutos — removida

Decisão: reabrir tarefa deve ser sempre possível, sem restrição de tempo.

- `CompletionLockedError` e `lock_expired_completions()` removidos
- `completion_locked` e `can_undo_completion` removidos dos schemas de resposta
- Novo endpoint `POST /tasks/{task_id}/restore`

### 3. Undo stack + atalhos de teclado

Novo contexto React `contexts/UndoContext.tsx`:
- Stack de até 10 operações reversíveis em memória
- Toast com botão "Desfazer" após cada ação destrutiva

Atalhos: Ctrl+Z (undo), Ctrl+N (nova tarefa), Escape (fecha modal), Ctrl+Enter (salva modal), Delete (deleta card focado), Enter (edita card focado)

### 4. Testes — 64 passando

- `conftest.py` corrigido: override de `get_current_user` faltava desde que auth foi implementada
- Testes de completion lock substituídos por testes de restore e undo sem restrição
