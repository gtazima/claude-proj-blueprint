### 2. Bugs de encadeamento de tarefas (concluídos)
- **Bug raiz 1**: picker no `CreateTaskModal` mostrava tarefas no meio de cadeias, permitindo criar cadeias paralelas. Fix: filtrar candidatos para `(t.chains?.length ?? 0) === 0` (tarefas sem cadeia) + chain tails existentes.
- **Bug raiz 2**: endpoint `unlink_task` retornava 204 sem corpo → título antigo ficava no cache até o refetch. Fix: mudar para 200 retornando `TaskRead`, frontend usa `setQueryData` para atualização imediata.
- **Bug raiz 3**: N+1 queries — `list_today` fazia 1 query por tarefa para carregar `chains`. Fix: `chain_infos_bulk()` no `ChainService` usando 2 queries para todas as tarefas.

### 3. Tarefas invisíveis `is_pending_review` (diagnosticado e corrigido)
- 3 tarefas ("Aplicação de tracer 1/3", "2/3") sumidas porque foram importadas do Google Tasks com `is_pending_review=True`. `list_today` excluía essas tarefas silenciosamente. Feature de revisão foi descartada há muito tempo no UX mas o filtro permaneceu no código.
- Fix aplicado: SQL `UPDATE task SET is_pending_review = false WHERE is_pending_review = true`, remoção do filtro em `services/tasks.py`, `google_sync.py` alterado para `is_pending_review=False`.
